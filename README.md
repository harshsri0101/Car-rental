# 🚗 Car Rental System

A full-stack web application that allows users to rent cars online.
Built using **MERN Stack (MongoDB, Express, React, Node.js)**.

---

## ✨ Features

* 🔐 User Authentication (Login/Register)
* 🚘 View Available Cars
* 📅 Book a Car
* 📖 View Bookings

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

---

## 📁 Project Structure

backend/ → API & server
frontend/ → React app

---

## 1. Backend setup

```bash
cd backend
npm install
npm start
```

### 2. Frontend setup

```bash
cd frontend
npm install
npm start
```

---

## 🌐 API

Base URL:

```
http://localhost:5002/api
```
